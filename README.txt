5-ALARM HEADLIGHT RESTORATION — WEBSITE VERSION 3

UPLOAD INSTRUCTIONS FOR GITHUB
1. Unzip this file on your computer.
2. Open the unzipped folder.
3. In your GitHub repository, click Add file > Upload files.
4. Drag ALL files and the assets folder into the upload area.
5. Confirm that the assets folder contains the .webp gallery images before committing.
6. Commit directly to the main branch.
7. Netlify will publish automatically.

IMPORTANT
Do not upload this ZIP file itself into GitHub. Upload the CONTENTS of the unzipped folder.
The before/after images are now directly inside /assets (not a nested gallery folder), which makes upload and deployment simpler.
